        공식 자료 자동 수집 상태를 확인하고 있습니다.
        춘봉 콘텐츠 자동 수집기한 번 설치

        나무위키 + SOOP 로그인 글 + FM코리아 공개글을 같은 브라우저 수집 큐로 처리합니다. 로그인 아이디·비밀번호·쿠키·세션 토큰은 수집하거나 팬사이트 서버로 전송하지 않습니다.

        자동 수집기 연결 대기설치 후 이 운영자 센터를 새로 열면 자동 연결됩니다.
        자동 수집기 설치 / 업데이트
        1. Chrome의 userscript 관리자(Tampermonkey 등)에 위 스크립트를 1회 설치합니다.
        2. 나무위키는 운영자 센터의 대기 목록을 한 번에 열어 본문·i.namu.wiki 이미지를 자동 수집합니다.
        3. SOOP은 최초에 SOOP 전체 기록 1회 수집을 실행하면 과거 게시판까지 순차적으로 훑습니다. 이미 처리한 글은 건너뛰고 중단 시 이어서 진행합니다. 완료 뒤에는 SOOP 신규 글 확인으로 새 글만 증분 수집합니다.
        4. SOOP 일반 공개글은 비로그인 상태에서도 열리는지 별도 확인해 공개 자료로 자동 연결합니다. 애청자·로그인 제한 글은 자동 연결 시 내부 자료로 유지하되, 운영자가 외부 공개 권한을 확인한 경우 수집 원문함에서 직접 공개로 전환할 수 있습니다.
        5. FM코리아는 비로그인 상태에서도 열리는 공개 게시글만 익명 재확인 후 수집합니다. 춘봉·레오펠·그냥서버·춘타클 등 관련 제목은 목록에서도 자동 감지합니다.
        6. FM코리아 공개글은 매칭이 확실한 기존 콘텐츠에 내부 검증 자료로 자동 연결하고, 동일 글 번호는 중복 수집하지 않습니다. 팬사이트에는 FM코리아 출처명·원문 링크를 표시하지 않으며, SOOP 로그인 제한 글도 자동 공개하지 않습니다.
        SOOP 로그인 글 수동 수집자동 수집기 보조

        자동 수집기를 설치하지 않은 경우 사용하는 수동 방식입니다. 로그인된 SOOP 글에서 제목·작성일·본문·이미지만 읽고 인증정보는 읽거나 전송하지 않습니다.

        SOOP 글 수집
        1. SOOP 글 수집 링크를 브라우저 북마크바로 끌어놓습니다.
        2. 애청자 공개글을 로그인된 상태로 연 뒤 그 북마크를 누릅니다.
        3. 운영자 센터로 돌아오면 수집 결과를 확인하고 기존 콘텐츠에 연결하거나 새 초안으로 만듭니다.

# 춘박게임 Immersive UI·사운드·콤보 개편 설계

## 목적

춘박게임을 춘트리스와 동일한 사용 흐름으로 정리한다. 게임 시작 전에는 닉네임과 보조 기능만 간결하게 보여주고, 플레이 중에는 게임 통을 중심으로 공간을 넓게 사용한다. 랭킹·소리·조작법은 필요할 때 팝업으로 열되, 왼쪽 `SCORE / BEST / MAX` 아래의 `GLOBAL TOP 10`은 플레이 중 상시 표시로 유지한다.

Matter.js 물리 규칙, 11단계 합체 규칙, 위험선 2초 게임오버 판정, 기존 점수 계산과 랭킹 API는 유지한다. 이번 변경은 UI 상태 흐름, 일시정지, 사운드 표현, 합체 연출과 콤보 표시를 중심으로 한다.

## 확정된 사용자 결정

- 닉네임은 선택 입력이다.
- 닉네임을 비워도 게임을 시작할 수 있다.
- 닉네임 공란 기록은 전체 랭킹에 POST하지 않고 로컬 BEST만 저장한다.
- 닉네임을 유효하게 입력한 경우에만 전체 랭킹 API에 기록한다.
- 플레이 중 랭킹/소리/조작법 팝업을 열면 자동 일시정지한다.
- 해당 팝업을 닫을 때 팝업을 열기 직전에 플레이 중이었다면 자동으로 계속한다.
- ESC 또는 일시정지 버튼으로 수동 일시정지할 수 있다.
- 수동 일시정지 팝업에서는 `계속하기 / 새 게임 / 소리 설정 / 조작법`을 제공한다.
- 콤보는 기존 시간 기반 규칙을 사용한다. 합체 뒤 1.25초 이내에 다음 합체가 발생하면 콤보가 증가한다. 다음 드롭에서 발생한 합체도 1.25초 안이면 같은 콤보로 이어진다.
- `COMBO x1`은 표시하지 않고 `COMBO x2`부터 표시한다.
- 플레이 화면 왼쪽의 `SCORE / BEST / MAX` 아래에는 전체 최고 기록 `GLOBAL TOP 10`을 상시 유지한다.
- 시작 화면과 플레이 중 우측 상단의 랭킹 버튼도 유지하며, 랭킹을 더 크게 볼 수 있는 모달을 연다.

## 화면 상태

춘박게임은 아래 상태를 명확하게 구분한다.

1. `start`
   - 게임 통은 플레이 UI로 노출하지 않는다.
   - 중앙 시작 카드에 닉네임 입력과 `게임 시작` 버튼을 표시한다.
   - 닉네임 필드는 `선택`임을 명시한다.
   - 하단에 `전체 랭킹 / 소리 설정 / 조작법` 버튼을 둔다.

2. `playing`
   - Matter.js 엔진을 업데이트한다.
   - 드롭 입력을 허용한다.
   - 게임 영역 우측 상단 유틸리티 버튼을 표시한다.

3. `paused`
   - Matter.js 엔진 업데이트를 중지한다.
   - 현재 월드, 점수, 다음 캐릭터, 콤보, 위험선 상태를 유지한다.
   - 수동 일시정지 팝업을 표시한다.

4. `utility-modal`
   - 플레이 중 랭킹/소리/조작법 모달을 열면 자동 일시정지한다.
   - 모달을 닫을 때 직전 상태가 `playing`이었던 경우에만 재개한다.
   - 이미 수동 일시정지 상태에서 열린 모달이라면 닫아도 게임을 자동 재개하지 않는다.

5. `gameover`
   - 기존 게임오버 오버레이를 유지한다.
   - 로컬 BEST를 저장한다.
   - 유효한 닉네임이 있을 때만 전체 랭킹을 제출한다.

## 시작 화면

시작 화면은 춘트리스의 시작 카드 패턴을 따른다.

구성:

- `춘박게임` 제목과 짧은 설명
- 닉네임 입력 필드
  - placeholder는 선택 입력임을 알 수 있게 한다.
  - 유효 닉네임: 기존 `ChunbakRankingCore.validateNickname()` 규칙 유지
  - 공란은 오류가 아니다.
- `게임 시작` 버튼
- 보조 버튼 3개
  - `🏆 전체 랭킹`
  - `🔊 소리 설정`
  - `⌨ 조작법`

게임 시작 시 시작 화면은 숨기고 플레이 화면이 같은 게임 컨테이너를 차지한다. 아래쪽에 별도 게임 UI가 추가되는 방식으로 만들지 않는다.

## 플레이 레이아웃

데스크톱은 3열 중심으로 구성한다.

### 왼쪽

- `SCORE`
- `BEST`
- `MAX`
- `GLOBAL TOP 10`
  - 현재 전체 최고 기록 10개를 상시 표시한다.
  - 기존 랭킹 렌더링과 API를 재사용한다.

### 중앙

- 춘박 게임 통
- 위험선
- 드롭 프리뷰
- 합체 이펙트 레이어
- 콤보 텍스트 레이어
- 게임오버 오버레이

게임 통은 기존 420×680 논리 좌표를 유지하며 CSS로만 반응형 확대/축소한다. 물리 좌표계를 변경하지 않는다.

### 오른쪽

- `NEXT`
- `EVOLUTION 1 → 11`
- 단계표

기존 상시 조작법 패널은 제거하고 팝업으로 이동한다.

### 우측 상단 유틸리티

게임 영역 바깥 우측 상단에 다음 버튼을 둔다.

- `🏆 랭킹`
- `🔊 소리`
- `⌨ 조작법`
- `⏸ 일시정지`

버튼은 게임 통 위를 가리지 않으며 키보드 접근이 가능해야 한다.

## 모달 시스템

공통 모달 컨테이너를 사용해 랭킹, 소리, 조작법, 일시정지 패널을 전환한다.

### 랭킹 모달

- `GLOBAL TOP 10`
- 랭킹 상태 문구
- 플레이 화면 왼쪽 TOP 10과 동일한 데이터를 사용한다.
- 별도 API 중복 요청은 필요할 때만 한다.

### 소리 설정 모달

- 효과음 ON/OFF
- 볼륨 0~100 range
- 기존 localStorage 키를 유지한다.
  - `chunbak.sound.enabled.v1`
  - `chunbak.sound.volume.v1`

### 조작법 모달

- PC: 마우스로 위치 이동 후 클릭하여 드롭
- 모바일: 원하는 위치를 터치해 드롭
- ESC: 일시정지/계속하기
- 위험선 위에 약 2초 머물면 게임오버

### 일시정지 모달

- `계속하기`
- `새 게임`
- `소리 설정`
- `조작법`

`계속하기`는 현재 Matter.js 월드와 모든 기록 상태를 그대로 보존한다.

`새 게임`은 현재 판을 버리고 점수·MAX·콤보·월드를 초기화하되 닉네임과 소리 설정은 유지한다.

## 랭킹 저장 정책

`currentNickname()`은 다음 두 상태를 구분한다.

- 공란: 플레이 허용, 전체 랭킹 제출 생략
- 비어 있지 않음: 기존 validation을 통과한 경우에만 전체 랭킹 제출

공란으로 게임오버가 발생했을 때 `닉네임은 2~16자...` 같은 오류 메시지를 보여주지 않는다. 대신 로컬 BEST 저장만 완료한다.

닉네임을 잘못 입력한 상태에서 게임을 시작하는 경우도 플레이 자체는 막지 않는다. 다만 전체 랭킹 제출은 생략하고, 필요하면 랭킹 모달/상태 문구에서 입력 조건을 안내한다.

## 일시정지 동작

물리 엔진은 현재 `tick()`에서 `playing`일 때만 `Matter.Engine.update()`를 호출하므로 이 구조를 확장해 일시정지를 구현한다.

보존 대상:

- Matter.js world/body 상태
- score
- best
- maxLevel
- currentStage
- nextStage
- pointerX
- lastMergeAt
- combo
- dangerStartedAtById

일시정지 동안 위험선 타이머가 실제 경과 시간 때문에 즉시 게임오버가 되지 않도록, 재개 시 위험선 추적 시작 시각과 `lastMergeAt` 등 시간 기반 상태를 pause duration만큼 보정한다. 즉 사용자가 메뉴를 오래 열어두어도 재개 직후 위험선/콤보 시간이 의도치 않게 만료되지 않아야 한다.

## 콤보

기존 `Core.nextCombo(previousMergeAt, nowMs, previousCombo)`의 1250ms 규칙을 유지한다.

- 첫 합체: combo = 1, 화면 표시 없음
- 1.25초 안의 두 번째 합체: `COMBO x2`
- 이후 1.25초 안의 합체: `COMBO x3`, `COMBO x4` ...
- 1.25초를 넘긴 다음 합체: combo = 1로 재시작

현재 `scoreMerge(resultStage, combo)`가 콤보 보너스를 계산하므로 표시 수치와 점수 계산 수치는 동일한 combo 값을 사용한다.

콤보 텍스트는 게임 통 중앙 또는 최근 합체 지점 근처에 짧게 나타난다. 높은 콤보일수록 크기와 반짝임을 점진적으로 강화하되 플레이를 가리지 않는다.

## 합체 이펙트

합체 이벤트의 실제 좌표 `(x, y)`를 presentation layer에 전달해 물리 판정과 분리된 이펙트를 재생한다.

단계별 강도:

- 결과 2~4단계: 작은 반짝이 + 짧은 통통 링
- 결과 5~7단계: 별/하트 파티클 + 조금 큰 링
- 결과 8~10단계: 글로우 + 별/하트 파티클 증가 + 확장 링
- 결과 11단계: 가장 강한 축하 연출, 짧은 왕관/컨페티 계열 효과

파티클은 DOM/CSS 또는 캔버스 오버레이 중 성능이 안정적인 방식을 사용하되 Matter.js body에는 영향을 주지 않는다.

`prefers-reduced-motion: reduce`에서는 이동/확대 파티클을 최소화하고 짧은 플래시와 콤보 텍스트 위주로 대체한다.

## 사운드 디자인

기존 Web Audio API 구조와 저장 설정은 유지하되 음색을 캐주얼하고 귀엽게 변경한다.

목표 감각:

- `start`: 밝고 짧은 시작 징글
- `drop`: 가볍고 말랑한 `톡`
- 낮은 단계 합체: `뽁/딩` 계열
- 중간 단계 합체: 밝은 벨/마림바 계열의 2음
- 높은 단계 합체: 반짝이는 상승 아르페지오
- 11단계 합체: 짧은 축하 징글
- `gameover`: 무겁거나 공포스럽지 않은 부드러운 하강음

외부 오디오 파일은 추가하지 않고 Web Audio oscillator/gain으로 생성한다.

합체 단계에 따라 음 높이/화음을 변화시키기 위해 `playMerge(stage, combo)` 같은 단계 인자를 받는 API 또는 단계별 이벤트를 추가한다. UI는 오디오 구현 세부사항에 의존하지 않는다.

## 모바일

모바일은 1열로 쌓되 플레이 우선순위를 다음처럼 둔다.

1. 게임 상태/유틸리티
2. 게임 통
3. SCORE/BEST/MAX
4. NEXT
5. GLOBAL TOP 10
6. EVOLUTION

단, 실제 화면 크기에 따라 SCORE/BEST/MAX를 게임 통 위에 두는 기존 패턴이 더 읽기 좋으면 유지할 수 있다. 핵심 계약은 게임 통이 viewport 폭을 넘지 않고, TOP 10이 삭제되지 않으며, 우측 상단 유틸리티가 모바일에서도 접근 가능하다는 것이다.

모달은 작은 화면에서 bottom-sheet 형태의 전체 폭 패널로 보여준다.

## 접근성

- 모든 유틸리티 버튼에 `aria-label`을 제공한다.
- 모달은 `role="dialog"`, 적절한 제목 연결, 닫기 버튼을 제공한다.
- ESC는 열려 있는 일반 모달을 먼저 닫고, 모달이 없을 때 플레이 중이면 일시정지를 연다.
- 키보드 focus가 모달 뒤의 게임에 남아 우발 입력을 만들지 않도록 한다.
- reduced-motion을 지원한다.

## 오류 처리

- 랭킹 GET 실패: 게임은 정상 플레이 가능하며 팝업/왼쪽 랭킹에 오류 상태만 표시한다.
- 랭킹 POST 실패: 로컬 BEST는 유지하고 게임 흐름을 막지 않는다.
- 오디오 미지원 브라우저: 소리만 no-op 처리하고 게임은 정상 동작한다.
- 캐릭터 이미지 preload 실패: 기존처럼 게임 시작을 막고 명확한 상태 문구를 표시한다.

## 테스트 계약

### 상태/시작

- 시작 화면에서 닉네임 공란으로 `게임 시작` 가능
- 시작 후 시작 카드가 숨고 플레이 화면이 같은 컨테이너를 차지
- 공란 닉네임 게임오버 시 랭킹 POST 없음
- 유효 닉네임 게임오버 시 기존 랭킹 POST 수행

### 일시정지

- ESC와 일시정지 버튼 모두 동일한 pause 경로 사용
- pause 동안 Matter.js update 없음
- `계속하기` 후 기존 body 위치/점수/NEXT/콤보 유지
- pause 시간이 위험선 2초와 combo 1.25초를 소비하지 않음
- `새 게임`만 판 상태 초기화

### 모달

- 랭킹/소리/조작법 버튼이 시작 화면과 플레이 화면에서 동작
- 플레이 중 유틸리티 모달 열기 → 자동 pause
- 해당 모달 닫기 → 이전이 playing이면 자동 resume
- 이미 paused 상태에서 열린 모달 닫기 → paused 유지

### 랭킹 UI

- 데스크톱 플레이 왼쪽에 `SCORE/BEST/MAX` 아래 `GLOBAL TOP 10` 상시 존재
- 랭킹 모달도 TOP 10 표시
- 모바일에서도 TOP 10 접근 가능

### 사운드

- ON/OFF와 volume localStorage 유지
- start/drop/merge/high-stage/11-stage/gameover의 캐주얼 사운드 경로 검증
- 음소거 상태에서는 새 이펙트 사운드도 재생하지 않음

### 이펙트/콤보

- 합체 좌표에 effect가 생성됨
- 결과 단계별 effect intensity 클래스/데이터가 다름
- x1은 미표시, x2 이상 `COMBO xN` 표시
- 1250ms 이내 다음 합체는 콤보 증가
- 1250ms 초과 후 합체는 combo 1로 재시작
- reduced-motion 환경에서 축소 연출 사용

# Mobile App Shell 2.0 설계

## 목표

모바일 팬사이트를 데스크톱 화면의 축소판이 아니라 앱처럼 사용하도록 재구성한다.

핵심 목표:
- 모바일 홈을 1~2회 스크롤 안에 핵심 정보가 보이는 대시보드로 압축
- 하단 탭바를 모바일의 주 내비게이션으로 사용
- 상단 헤더를 페이지 제목 + 최소 액션만 남긴 앱바로 단순화
- 일정/데이터의 핵심 UI에서 필수 가로 스크롤 제거
- 긴 표는 카드형 정보로 변환
- 긴 데이터 그래프는 세로 나열 대신 의도적인 가로 스와이프 레일로 압축
- 모바일에서는 마케팅형 히어로/푸터보다 실제 콘텐츠를 먼저 보여줌
- 일반 모바일 브라우저와 설치형 PWA가 같은 UX 규칙을 사용

## 모바일 앱 셸

### 상단 앱바
모바일에서는 모든 일반 페이지에 compact header를 적용한다.

표시:
- 브랜드 마크
- 현재 페이지 제목
- 검색
- 알림

숨김/이동:
- MY 팬허브 → 하단 더보기
- 업데이트 일지 → 하단 더보기
- 테마 → 하단 더보기의 테마 버튼
- PC 전체 메뉴 → 하단 더보기

LIVE 상태는 홈 대시보드에서 우선 표시한다.

### 하단 탭
항상 고정:
- 홈
- 일정
- 타로
- 미니게임
- 더보기

더보기는 Bottom Sheet로 열며 공지, VOD, 클립, 팬아트, YouTube, 방송 이력, 데이터, MY, 업데이트, 테마 설정을 제공한다.

## 홈

모바일에서는 기존 설치형 PWA 대시보드를 일반 모바일에도 적용한다.

표시 순서:
1. 오늘의 팬허브
2. LIVE 또는 다음 일정
3. 오늘의 타로 / 오늘의 미션 / 이어보기 / MY
4. 최근 공지/콘텐츠 2개 정도의 스와이프 레일
5. SOOP / 팬카페 / YouTube compact buttons

모바일에서는 기존 큰 hero, 바로가기 카드, 전체 메뉴 섹션, quick stats를 숨긴다. 하단 더보기가 메뉴 역할을 대신한다.

## 페이지 히어로

모바일 일반 페이지에서는:
- 이미지 숨김
- 설명문은 숨김
- 외부 CTA는 더보기/본문으로 이동
- kicker + 페이지 제목만 compact하게 표시

콘텐츠가 화면 진입 직후 시작되도록 한다.

## 방송 일정

- 보기 방식 3개는 가로 스크롤 없이 3분할 segmented control
- 7일 빠른 선택은 7열 grid
- 선택된 날짜를 다시 누르면 전체 일정으로 복귀
- 월간 캘린더는 7열을 화면 폭 안에 표시
- 날짜 셀에는 상세 텍스트 대신 일정 존재 여부 점/개수만 표시
- 날짜를 누르면 달력 아래 detail card에 일정 목록을 표시
- 일정 카드의 캘린더 추가/공유 기능은 유지

## 춘봉 데이터

### 상단
- SOOP/YouTube는 2분할
- 핵심만 보기/상세 분석은 sticky segmented control 유지

### 상세 분석
- 일별/월별/캘린더는 3분할
- 그래프 여러 개는 한 줄 swipe rail
- 표는 가로 스크롤 테이블 대신 카드형 rows
- 캘린더는 화면 안 7열
- 방송 날짜는 점으로 표시하고 탭하면 아래 detail card
- 카테고리와 방송 세션은 기존 데이터를 유지하되 모바일 밀도 축소

## 기타 페이지

- 모바일 footer 숨김
- 타로 선택 dock, 미디어 mini player, 알림 Bottom Sheet는 기존 유지
- 팬아트/영상/공지 등은 첫 화면에서 콘텐츠가 바로 시작되도록 hero compact 적용
- 터치 영역 44px 이상 유지
- prefers-reduced-motion 유지

## 가로 스크롤 원칙

허용:
- 그래프 carousel
- 최근 콘텐츠 carousel
- 선택형 chip rail처럼 의도가 명확한 UI

금지:
- 월간 캘린더
- 데이터 표
- 핵심 페이지 탭

## 완료 기준

- 390px 화면에서 schedule/data calendar의 scrollWidth가 clientWidth를 초과하지 않음
- 데이터 detail table이 가로 스크롤 없이 카드로 표시됨
- 모바일 홈에서 hero/portal 중복 섹션이 숨겨짐
- 일반 모바일 브라우저에서도 앱형 홈/compact header가 적용됨
- 더보기에서 테마 변경 가능
- 데스크톱 레이아웃 변화 없음

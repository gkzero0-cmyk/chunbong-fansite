# 춘박게임 + 미니게임 허브 설계

## 목적
춘봉 팬사이트에 상위 메뉴 **미니게임**을 추가하고, 기존 춘트리스와 새 **춘박게임**을 하나의 허브에서 선택할 수 있게 한다. 춘박게임은 첨부된 1~11단계 투명 PNG 캐릭터를 사용하는 수박게임 스타일 합체 퍼즐이며, 기존 춘트리스와 같은 Vercel + Upstash Redis 패턴으로 전체 TOP 10 랭킹을 제공한다.

## 확정된 요구사항
- 상단 네비게이션의 기존 `춘트리스` 단독 항목을 `미니게임`으로 교체한다.
- 홈 카드 그리드에도 `미니게임` 카드를 추가한다.
- 새 `minigames.html`에서 `춘트리스`와 `춘박게임`을 선택할 수 있게 한다.
- 기존 `chuntris.html` URL은 그대로 유지해 기존 링크를 깨지 않는다.
- 새 게임 페이지는 `chunbak.html`로 만든다.
- 첨부된 11장의 1254×1254 RGBA PNG를 1~11단계 게임 오브젝트로 사용한다.
- 같은 단계 2개가 충돌하면 다음 단계 1개로 합체한다.
- 11단계 + 11단계는 더 이상 합체하지 않는다.
- 전체 유저 TOP 10 랭킹 + 닉네임 입력 방식을 제공한다.

## 사이트 구조
- `index.html`
  - 상단 네비게이션에 `미니게임 → minigames.html`
  - 홈 카드 그리드에 `미니게임` 카드
- `minigames.html`
  - 춘트리스 카드 → `chuntris.html`
  - 춘박게임 카드 → `chunbak.html`
- `chuntris.html`
  - 기존 주소 유지
- `chunbak.html`
  - 새 게임 화면

## 춘박게임 플레이 규칙
### 물리
- Matter.js 기반 2D 물리엔진을 사용한다.
- 좌우 벽과 바닥은 정적 충돌체로 구성한다.
- 캐릭터는 각 단계별 반지름을 갖는 원형 충돌체를 사용하고, 원본 PNG를 렌더링한다.
- PC는 마우스 이동 + 클릭, 모바일은 터치 위치 + 탭으로 캐릭터를 떨어뜨린다.
- 충돌 이벤트에서 같은 단계인지 확인한 뒤 두 바디를 제거하고 다음 단계 바디를 생성한다.
- 동일 충돌이 여러 번 처리되지 않도록 merge lock/debounce를 둔다.

### 등장 단계
새로 떨어지는 캐릭터는 1~5단계만 등장한다.

기본 확률:
- 1단계 35%
- 2단계 27%
- 3단계 18%
- 4단계 12%
- 5단계 8%

6~11단계는 합체로만 만든다.

### 점수
합체로 새로 만들어진 단계 기준으로 점수를 부여한다.
- 2단계: 20
- 3단계: 40
- 4단계: 80
- 5단계: 140
- 6단계: 220
- 7단계: 340
- 8단계: 520
- 9단계: 760
- 10단계: 1080
- 11단계: 1500

연속 합체가 약 1.25초 안에 이어질 경우 콤보를 증가시키고 소규모 추가 점수를 제공한다. 콤보는 랭킹 동점 기준에는 사용하지 않는다.

### 게임오버
- 상단 위험선을 캐릭터가 순간적으로 넘는 것만으로 게임오버 처리하지 않는다.
- 어떤 캐릭터가 위험선 위에 약 2초 연속 머물면 게임오버 처리한다.

## 랭킹
### API
기존 `/api/content` 멀티플렉서를 재사용한다.

- GET: `/api/content?type=chunbak-ranking&mode=classic`
- POST: `/api/content?type=chunbak-ranking`

POST 데이터:
```json
{
  "mode": "classic",
  "nickname": "player",
  "score": 1234,
  "maxLevel": 8
}
```

### 저장
- 기존 Upstash Redis 환경변수를 그대로 재사용한다.
- Redis key: `chunbak:classic:players`
- 새 Vercel Function 엔트리는 추가하지 않는다.

### 정렬 및 갱신
- 같은 닉네임은 최고 기록 1개만 유지한다.
- 우선순위: 높은 `score` → 높은 `maxLevel` → 더 이른 `achievedAt`.
- TOP 10만 클라이언트에 노출한다.

## 오류 처리
- 랭킹 API가 실패해도 게임 플레이 자체는 가능해야 한다.
- 랭킹 패널에는 `랭킹을 불러올 수 없습니다` 상태를 표시한다.
- 닉네임이 유효하지 않으면 점수 전송을 막고 인라인 오류를 보여준다.
- 핵심 캐릭터 이미지 로딩 실패 시 게임 시작을 막고 명확한 오류를 표시한다.

## 테스트
단위 테스트:
- 닉네임 정규화/검증
- 점수/최고 단계 검증
- 랭킹 정렬 및 better-record 판정
- 1+1→2
- 10+10→11
- 11+11 미합체
- 신규 스폰이 1~5단계만 반환되는지 확인

통합 테스트:
- 홈에 미니게임 카드가 있는지 확인
- 상단에 미니게임 링크가 있는지 확인
- `minigames.html`에 춘트리스/춘박게임 카드가 모두 있는지 확인
- 춘박게임 주요 UI 요소 존재 확인
- 랭킹 GET/POST 검증

Production smoke:
- `minigames.html` 200
- `chunbak.html` 200
- 1~11단계 PNG 200
- 랭킹 GET 정상
- 잘못된 닉네임 POST가 예상 오류 반환
- 대표 PC/모바일 viewport에서 가로 overflow 및 게임판 잘림 없음
- 실제 캐릭터 드롭/합체/재시작 기본 동작 확인

## 완료 기준
- 상단 네비게이션과 홈 카드 그리드에 `미니게임`이 보인다.
- 미니게임 허브에서 춘트리스와 춘박게임으로 이동할 수 있다.
- 기존 `chuntris.html`이 계속 동작한다.
- `chunbak.html`에서 PC/모바일 모두 실제 플레이가 가능하다.
- 첨부된 11단계 캐릭터 이미지가 게임에 사용된다.
- 11단계는 최종 단계이며 추가 합체되지 않는다.
- 전체 TOP 10 랭킹이 기존 Upstash 기반 API 구조로 동작한다.
- 관련 회귀 테스트와 Production smoke가 통과한다.

# 춘봉 팬사이트 TAROT 기능 설계

## 목표

춘봉 팬사이트에 별도 설치나 AI API 없이 브라우저에서 바로 사용할 수 있는 78장 풀덱 타로 기능을 추가한다. 사용자는 1장 또는 3장 스프레드를 선택하고, 카드를 직접 뽑아 정방향/역방향 결과와 카드별 해석 및 전체 리딩을 확인할 수 있다.

## 범위

- 상단 네비게이션에 `TAROT` 메뉴 추가
- 메인 포털에 `07 / TAROT · 타로 보기` 카드 추가
- 새 페이지 `tarot.html` 추가
- 78장 카드 데이터와 웹 최적화 카드 이미지 추가
- 1장/3장 리딩, 정·역방향, 카드 셔플/선택/플립 애니메이션 제공
- 모바일/데스크톱 반응형 지원
- AI API, 사용자 계정, 서버 저장, 결제 기능은 이번 범위에서 제외

## 카드 자산

사용자 제공 ZIP을 원본으로 사용한다.

- 메이저 아르카나: `춘봉 메이저 아르카나(1).zip` 22장
  - 파일: `0번.png` ~ `21번.png`
  - 표준 메이저 아르카나 번호에 매핑
    - 0 바보
    - 1 마법사
    - 2 여사제
    - 3 여황제
    - 4 황제
    - 5 교황
    - 6 연인
    - 7 전차
    - 8 힘
    - 9 은둔자
    - 10 운명의 수레바퀴
    - 11 정의
    - 12 매달린 사람
    - 13 죽음
    - 14 절제
    - 15 악마
    - 16 탑
    - 17 별
    - 18 달
    - 19 태양
    - 20 심판
    - 21 세계
- 마이너 아르카나: `마이너 아르카나.zip` 56장
  - 소드/완드/컵/펜타클 각 14장
  - 에이스, 2~10, 시종, 기사, 여왕, 왕

원본 PNG 총 용량이 약 223MB이므로 사이트에는 동일 이미지를 WebP로 변환해 사용한다. 목표는 카드 비율을 유지하면서 긴 변 기준 약 1152px 이내, 시각 품질을 보존하는 수준으로 압축하여 초기 로딩과 Vercel 배포 용량을 줄이는 것이다. 메이저 12번 원본은 1055×1491이며 나머지는 대부분 1024×1536이므로 CSS `object-fit: contain`으로 비율 차이를 흡수한다.

## 사용자 흐름

1. 사용자가 `TAROT` 페이지에 진입한다.
2. 리딩 주제를 선택한다.
   - 오늘의 타로
   - 고민 상담
   - 연애운
   - 금전운
   - 방송·게임운
3. 카드 수를 선택한다.
   - 1장
   - 3장
4. 3장을 선택한 경우 스프레드를 선택한다.
   - 과거 · 현재 · 미래
   - 상황 · 조언 · 결과
5. 선택적으로 질문을 입력한다.
6. `카드 섞기`를 누르면 카드 뒷면이 움직이는 셔플 애니메이션을 보여준다.
7. 사용자가 필요한 수만큼 카드를 직접 선택한다.
8. 선택한 카드를 순서대로 플립해 카드 이미지와 정방향/역방향을 공개한다.
9. 카드별 해석과 전체 리딩을 표시한다.
10. 사용자는 `다시 뽑기` 또는 `다른 질문 보기`를 선택한다.

## 랜덤 처리

- 78장 전체에서 중복 없이 추출한다.
- 정/역방향은 카드마다 독립적으로 50% 확률로 결정한다.
- 가능한 경우 `crypto.getRandomValues()`를 사용해 브라우저 내 랜덤 값을 만든다.
- 역방향 카드는 이미지 컨테이너를 180도 회전해 시각적으로 표시한다.
- 카드 선택 결과는 서버에 전송하거나 저장하지 않는다.

## 카드 데이터 모델

각 카드는 다음 정보를 가진다.

- `id`: 고유 식별자
- `arcana`: `major` 또는 `minor`
- `number` 또는 `rank`
- `suit`: 마이너일 경우 소드/완드/컵/펜타클
- `nameKo`: 한국어 카드명
- `image`: 최적화된 WebP 경로
- `keywordsUpright`: 정방향 핵심 키워드
- `keywordsReversed`: 역방향 핵심 키워드
- `meaningUpright`: 정방향 기본 해석
- `meaningReversed`: 역방향 기본 해석
- `topicHints`: 연애/금전/고민/방송·게임 주제별 보조 문구

해석 데이터는 정적 JavaScript 데이터로 포함한다. AI 호출 없이 카드 의미 + 주제 + 스프레드 위치를 조합해 문장형 결과를 만든다.

## 스프레드 해석

### 1장

- 선택 주제에 대한 현재 메시지와 조언 중심으로 표시한다.

### 과거 · 현재 · 미래

- 1번 카드: 과거 — 배경, 이미 지나온 영향
- 2번 카드: 현재 — 현재 핵심 상태
- 3번 카드: 미래 — 이어질 가능성 또는 방향

### 상황 · 조언 · 결과

- 1번 카드: 상황 — 현재 문제의 구조
- 2번 카드: 조언 — 취할 태도/행동
- 3번 카드: 결과 — 조언을 고려했을 때의 흐름

`전체 리딩`은 세 카드의 위치, 정/역방향, 메이저/마이너 비중을 이용해 짧은 종합 문장을 생성한다. 확정적 예언 대신 가능성과 자기성찰 중심의 표현을 사용한다.

## UI/비주얼

기존 팬사이트의 검정 배경 + 주황 포인트 톤을 유지하면서 타로 페이지에는 신비로운 분위기를 추가한다.

- 어두운 무대형 배경
- 카드 주변 금박/오렌지 글로우 효과
- 카드 뒷면은 CSS 기반 오리지널 패턴으로 제작
- 셔플 시 카드가 겹치며 이동하는 애니메이션
- 카드 선택 시 hover/tap 반응
- 결과 공개 시 3D flip
- 역방향은 180도 회전 표시
- 과도한 파티클/대용량 애니메이션 라이브러리는 사용하지 않는다
- `prefers-reduced-motion` 환경에서는 애니메이션을 단순화한다

## 파일 구조

예상 변경 파일:

- `index.html` — 상단 메뉴 및 포털 카드 추가
- 기존 각 페이지의 공통 네비게이션 — `TAROT` 메뉴 추가
- `tarot.html` — 새 타로 페이지
- `tarot.js` — 상태, 셔플, 선택, 랜덤, 결과 생성
- `tarot-data.js` — 78장 카드/해석 데이터
- `styles.css` — 타로 전용 스타일 추가
- `assets/tarot/major/*.webp`
- `assets/tarot/minor/*.webp`
- `tests/tarot-regression.mjs` — 기본 기능 회귀 테스트

기존 페이지 로직과 타로 로직은 분리해, 타로 기능 수정이 공지/CATCH/일정 기능에 영향을 주지 않도록 한다.

## 오류 처리

- 카드 이미지가 로드되지 않으면 카드명과 해석은 계속 표시하고 이미지 영역에 대체 텍스트를 보여준다.
- 브라우저에서 `crypto.getRandomValues`가 사용할 수 없는 경우에만 `Math.random()`으로 폴백한다.
- 질문 입력은 비어 있어도 진행 가능하다.
- 사용자가 카드 선택 중 페이지 크기를 변경해도 선택 상태는 유지한다.

## 접근성

- 카드 선택은 마우스뿐 아니라 키보드 Enter/Space로 가능하게 한다.
- 선택 가능 카드에 명확한 `aria-label`을 부여한다.
- 카드 결과는 이미지 외에 텍스트로 카드명/방향/해석을 제공한다.
- 모션 감소 설정을 존중한다.

## 안내 문구

결과 화면 하단에 다음 취지의 짧은 문구를 표시한다.

> 타로 결과는 재미와 자기성찰을 위한 참고용입니다. 중요한 결정은 현실의 정보와 판단을 함께 고려해 주세요.

## 테스트 기준

자동 테스트에서 최소 다음을 검증한다.

- 데이터가 정확히 78장인지
- 메이저 22장, 마이너 56장인지
- 모든 카드 ID가 고유한지
- 모든 카드 이미지 경로가 존재하도록 매핑되었는지
- 3장 추출 시 중복 카드가 없는지
- 두 3장 스프레드가 모두 정의되어 있는지
- `TAROT` 네비게이션/메인 포털 링크가 존재하는지
- 기존 CATCH/공지 회귀 테스트가 계속 통과하는지

## 완료 조건

- 팬사이트에서 `TAROT` 메뉴로 진입 가능
- 첨부된 78장 카드 이미지를 실제로 사용
- 1장 및 3장 뽑기 동작
- 3장 스프레드 2종 모두 동작
- 정/역방향 랜덤 및 시각 표시 동작
- 카드별 해석과 전체 리딩 표시
- 데스크톱/모바일 사용 가능
- 기존 팬사이트 기능의 회귀 테스트 통과
- Vercel 배포 성공
